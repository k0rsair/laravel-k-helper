# Eloquent inherited model fields and migration-based cast type suggestions

**Date:** 2026-05-20 21:45
**Files:** src/indexer/scanners.ts, src/indexer/index.ts, src/indexer/types.ts, src/context/completionContext.ts, src/providers/completionProvider.ts, test/unit/scanners.test.ts, test/unit/context.test.ts, test/fixtures/laravel-basic/app/Domain/CustomerProfile.php, test/fixtures/laravel-basic/database/migrations/2024_01_01_000000_create_users_table.php
**Severity:** medium

## Problem

Eloquent model attributes from migrations could be missing when a model inherited from an application base class instead of directly extending Laravel's `Model` or `Authenticatable`. The index also stored migration columns without their migration method type, so `$casts` value completions could not recommend a type based on the column.

## Root Cause

Model detection relied on a direct inheritance regex or the `app/Models` path. It did not build a PHP class inheritance graph, so models outside that path could be skipped when they inherited through a shared base class. Eloquent field de-duplication also ignored `modelClass`, so two models pointing at the same table could collapse each other's copied migration fields. Migration columns only carried names, not source column types.

## Solution

The Eloquent scanner now reads app PHP classes first, resolves `extends` references through imports/namespaces, and follows inheritance recursively to identify models that inherit from a detected Eloquent base. Migration columns now keep `columnType`, field de-duplication includes `modelClass`, and `$casts` value completions use the model field's migration type to prioritize Laravel cast suggestions. Completion context detection now handles multiline `$fillable`, `$guarded`, and `$casts` arrays.

## Prevention

- Test inherited Eloquent models outside `app/Models` when changing model detection.
- Include `modelClass` in uniqueness keys for model-scoped index records.
- Keep migration metadata with database column records when downstream completions need more than the column name.
- Cover both `$casts` keys and `$casts` values in context tests.
